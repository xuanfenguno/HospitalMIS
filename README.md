# 医院收费管理系统 (HIS-MVP)

基于 **Visual Studio 2022 + C++17** 开发的医院信息系统最小可行性产品（MVP），实现了"患者建档 → 挂号 → 开处方 → 收费 → 发药(扣库存)"的完整核心流程。

## 一、功能模块

| 模块 | 功能 |
|------|------|
| **门诊挂号** | 患者建档、挂号（选科室/医生）、查看今日挂号、退号 |
| **医生工作站** | 开处方（诊断+药品明细）、查看处方列表、查看处方明细 |
| **收费结算** | 收费（计算挂号费+药费）、打印票据、自动发药扣库存、退费 |
| **药房管理** | 药品库存查询、入库/出库、录入新药品 |
| **基础数据** | 患者管理、科室列表、医生管理 |
| **查询统计** | 挂号/处方/收费记录查询、今日挂号统计 |

## 二、技术栈

- **开发语言**：C++ 17
- **开发工具**：Visual Studio 2022（v143 工具集）
- **界面**：Windows 控制台（UTF-8 中文显示）
- **数据存储**：管道分隔文本文件（无第三方依赖，可直接编译）
- **架构**：三层架构（数据层 DataStore / 业务层 Service / 表现层 UI）

## 四、编译与运行

### 方法一：Visual Studio 2022（推荐）

1. 双击打开 `HospitalMIS.sln`
2. 选择配置：`Debug` 或 `Release`，平台：`x64`（或 `x86`）
3. 按 `Ctrl + F5`（开始执行不调试）或 `F5`（调试运行）
4. 程序会在可执行文件同级目录自动创建 `data/` 文件夹并初始化演示数据

### 方法二：命令行 MSBuild

```bash
# 在 HospitalMIS.sln 所在目录执行
msbuild HospitalMIS.sln /p:Configuration=Release /p:Platform=x64
```

生成产物在 `x64/Release/HospitalMIS.exe`，运行时确保 `data/` 目录在工作目录下。

## 五、快速体验：完整看病流程

首次运行系统已预置演示数据：**4个科室、4位医生、6种药品**。

### 步骤 1：患者建档
- 主菜单 → `5.基础数据` → `1.患者建档`
- 输入姓名、性别、年龄等信息，获得患者编号（如 P0001）

### 步骤 2：挂号
- 主菜单 → `1.门诊挂号` → `1.新增挂号`
- 选择患者 → 选择科室 → 选择医生 → 生成挂号单（如 R0001）

### 步骤 3：医生开处方
- 主菜单 → `2.医生工作站` → `1.开处方`
- 输入挂号号 → 录入诊断 → 添加药品（可添加多种）→ 生成处方（如 RX0001）

### 步骤 4：收费结算
- 主菜单 → `3.收费结算` → `1.收费`
- 输入处方号 → 查看费用清单 → 输入实收金额 → 打印票据 → 自动发药扣库存

### 步骤 5：查看结果
- 主菜单 → `6.查询统计` → 查看挂号/处方/收费记录
- 主菜单 → `4.药房管理` → `1.药品库存查询` 验证库存已扣减

## 六、数据文件说明

程序运行后在 `data/` 目录生成以下文件：

| 文件 | 内容 | 格式 |
|------|------|------|
| `patients.dat` | 患者信息 | 每行一条，`\|` 分隔 |
| `departments.dat` | 科室信息 | 每行一条 |
| `doctors.dat` | 医生信息 | 每行一条 |
| `drugs.dat` | 药品信息 | 每行一条 |
| `registrations.dat` | 挂号记录 | 每行一条 |
| `prescriptions.dat` | 处方记录 | 多行（头+明细+`<END>`） |
| `billings.dat` | 收费记录 | 每行一条 |
| `counters.dat` | ID 自增计数器 | key\|value |

删除 `data/` 目录可重置所有数据并重新生成演示数据。

## 七、扩展指南

本 MVP 采用分层架构，便于后续扩展：

### 1. 升级到 SQLite 数据库
- 添加 `sqlite3.h` / `sqlite3.c` 到项目（从 sqlite.org 下载）
- 在 `DataStore` 类内部将文件 IO 替换为 SQLite 调用
- 上层 Service 和 UI 代码无需任何修改

### 2. 添加图形界面（GUI）
- **方案 A（MFC）**：VS2022 安装 MFC 组件，将 ConsoleUI 替换为对话框/文档视图
- **方案 B（Qt）**：安装 Qt VS Tools，用 Qt 重写 UI 层，复用 Service 和 DataStore
- **方案 C（Win32 API）**：直接调用 Win32 API 创建窗口

### 3. 扩展功能模块
- **住院管理**：新增 Bed/Admission/Discharge 模型与服务
- **医保结算**：在 BillingService 中增加医保计算逻辑
- **权限管理**：新增 User/Role 模型，登录后按角色限制菜单
- **网络多用户**：将 DataStore 拆分为客户端/服务端，用 Socket 通信

### 4. 医疗标准对接
- 学习 **HL7** 标准：用于与 LIS（检验）、PACS（影像）系统交换数据
- 学习 **DICOM** 标准：用于医学影像存储与传输

## 八、关键设计说明

### 事务一致性
收费流程中"收费"与"发药扣库存"是关联操作：
- 先检查库存是否充足 → 再收款 → 再扣库存
- 若库存不足，收费仍记录但标记发药失败，需人工补货后处理

|------|------|------|
| P | 患者 | P0001 |
| D | 科室 | D0001 |
| T | 医生 | T0001 |
| G | 药品 | G0001 |
| R | 挂号 | R0001 |
| RX | 处方 | RX0001 |
| B | 票据 | B0001 |
